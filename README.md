# PTI Lab

Coursework and labs for PTI (Programació de Tecnologies d'Internet).

## Labs

- [Lab1](Lab1) — Web APIs: Node.js car rental app (`myapp`) with Express server, frontend, and Dockerfile.
- [Lab2](Lab2) — Agents: Python RAG/chatbot lab, vector index creation and querying over a car rental dataset.
- [Lab3](Lab3) — Microservices: car rental app deployed on Kubernetes, with Dockerfile, deployment/service/ingress/HPA manifests, and Node.js server.
- [Lab4](Lab4) — Blockchain (not started yet).
- [Lab5](Lab5) — Machine Learning-based Applications (not started yet).
